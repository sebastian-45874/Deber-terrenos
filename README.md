# Deber: Terreno en Unity - Avenida de los Volcanes

## Descripción del Proyecto
Proyecto desarrollado en Unity 6 que representa un paisaje andino inspirado en la "Avenida de los Volcanes" en Ecuador, incluyendo un valle montañoso, formaciones volcánicas con cimas nevadas, vegetación de páramo y una laguna al costado rodeada por elementos y ruinas, que representa la época de 1800

## Cómo Ejecutar el Proyecto
1. Clona o descarga este repositorio en tu computadora.
2. Abre **Unity Hub** y crea un nuevo proyecto en blanco utilizando **Unity 6**.
3. Una vez abierto el editor, arrastra el archivo **`terreno.unitypackage`** dentro de la ventana de tu proyecto en Unity (o ve al menú superior *Assets > Import Package > Custom Package...* y selecciónalo).
4. Asegúrate de marcar todos los elementos en la ventana que aparece y haz clic en **Import**.
5. En la ventana *Project*, dirígete a la carpeta de escenas para visualizar el terreno.
6. Presiona el botón de **Play** en la parte superior central para iniciar la simulación.

## Cómo Navegar por la Escena
El usuario controla un cubo (`Player`) que recorre el terreno mediante las siguientes teclas:
- **W**: Avanzar hacia adelante.
- **S**: Retroceder.
- **A**: Rotar hacia la izquierda.
- **D**: Rotar hacia la derecha.
